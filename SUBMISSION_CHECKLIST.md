# Submission checklist

## Project

- [ ] Push the standalone project to `https://github.com/ayush1203kr/snapdeal-virtual-kam`.
- [ ] Confirm the repository opens without authentication and contains the source tree, README, technical note and demo script.
- [ ] Add a short repository description: `Voice-first AI Virtual KAM for seller sales diagnosis, recovery actions and follow-up`.
- [ ] Run `npm install`, `npm test` and `npm run build` locally after dependencies are available.
- [ ] Start MongoDB, run `npm run dev`, and verify the dashboard loads.
- [ ] Configure Gemini only if a key is available; never commit `.env` or an API key.

## Demo recording

- [ ] Record a 1–2 minute screen walkthrough using `DEMO_SCRIPT.md`.
- [ ] Show the dashboard and explain the revenue, traffic and conversion movement.
- [ ] Use the microphone for at least one seller message.
- [ ] Show the focused clarification and prioritized recovery plan.
- [ ] State an explicit commitment with a future due date.
- [ ] Show the saved commitment and trigger its in-app follow-up check-in.
- [ ] Keep the prototype and synthetic-data disclaimer visible or mention it.

## Final email/package

- [ ] Include the public GitHub repository URL.
- [ ] Include the 1–2 minute demo recording URL or attachment.
- [ ] Include `TECH_NOTE.md` or its contents as the brief AI/voice technology note.
- [ ] Include a concise explanation of the diagnosis → action → commitment → follow-up loop.
- [ ] Do not claim live Snapdeal integration or automated notifications; neither is implemented in this prototype.
